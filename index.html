    Como Usar o Calendário

    Navegação no Calendário

    Use os botões e para navegar entre os meses. Clique em "Hoje" para voltar ao mês atual.

    Busca Rápida

    Use o seletor de mês/ano no topo para ir diretamente para qualquer mês. Selecione o mês e ano desejados e clique na lupa.

    Modo de Visualização

    Clique no botão "Estações" para mostrar/ocultar os ícones das estações do ano nos dias.

    Tema Escuro/Claro

    Use o botão no canto superior direito para alternar entre os modos claro e escuro.

    Criar Eventos

    Clique em qualquer dia para adicionar um compromisso. Você pode categorizar como Pessoal, Trabalho, Saúde ou Lazer.

    Editar/Excluir Eventos

    Clique no indicador colorido do evento para editá-lo ou excluí-lo. No modal do dia, clique no evento específico.

    Lista de Compromissos

    Use o painel lateral para ver todos os compromissos do mês. Em dispositivos móveis, use o botão "Compromissos".

    Cores dos Eventos

    Cada categoria tem uma cor específica. Use a legenda no rodapé do calendário para identificar cada tipo.

    Feriados Nacionais

    Feriados são carregados automaticamente e mostrados com ícones vermelhos. Não podem ser editados ou excluídos.

    Pontos Facultativos

    Mostrados em laranja. Consulte sua empresa/órgão sobre a aplicação.

    Feriados Religiosos

    Mostrados em azul. Podem variar conforme a região.

    Feriados Locais

    Mostrados em roxo. Específicos de estados ou municípios.

    Eventos Recorrentes

    Ao criar um evento, marque "Evento recorrente" para configurar recorrência diária, semanal, mensal ou anual.

    Configuração de Recorrência

    Escolha o tipo de recorrência e configure os detalhes. Você pode definir um fim específico ou número de ocorrências.

    Gerenciamento de Recorrências

    Clique em um evento recorrente para: editar apenas essa ocorrência, excluir apenas essa ocorrência, ou excluir toda a série.

    Exclusões de Série

    Se excluir uma ocorrência específica, ela será removida apenas dessa data, mantendo as demais da série.

    Meus dados são salvos?

    Sim, todos os seus eventos são salvos localmente no seu navegador. Nenhum dado é enviado para servidores externos.

    Posso usar em múltiplos dispositivos?

    Os dados são salvos apenas no dispositivo atual. Para sincronização entre dispositivos, você precisaria usar a funcionalidade de exportar/importar (futura implementação).

    Como limpar todos os dados?

    Use o botão "Limpar Dados Salvos" no canto inferior direito (ou superior direito em mobile). Esta ação não pode ser desfeita!

    Os feriados são atualizados automaticamente?

    Sim, os feriados nacionais são carregados automaticamente de uma API pública. Se houver falha na conexão, serão usados feriados fixos.

    Posso mudar o fuso horário?

    Sim, use o seletor de fuso horário no cabeçalho para escolher o fuso da sua região. Isso afeta o relógio e a data atual.

    O site funciona offline?

    Sim, após o primeiro carregamento, o site funciona offline. Eventos e configurações são salvos localmente.

    Dica Rápida

    Clique duas vezes em um dia para criar rapidamente um evento pessoal.
